## 9-3  电场力的功  电势

### 1. 电场力的功

$$W _{ab} = \sum _1 ^n \frac{q _0 q _i}{4} \pi \varepsilon_0 = \frac{1}{r _{ai}} - \frac{1}{r _{bi}}$$

静电力是保守力,电场是保守场.

### 2. 静电场的环路定理

oint[l] _E_ cdot d _l_ = 0

### 3. 电势能

E[pa] = int[a..infty] q[0] _E_ cdot d _l_

### 4. 电势  电势差

电压 = [
  E[pa] / p[0]
  int[a..infty] _E_ cdot d _l_
] = U[a]

电势差 = [
  U[a] - U[b]
  int[a..b] _E_ cdot d _l_
] = U[ab]

W[ab] = q[0] (U[a] - U[b])

### 5. 电势的计算

点电荷电场的电势 {
  _E_ = (
    q / 4 pi varepsilon[0]
    _r_[0] r(2)
  )

  U[a] = q / 4 pi varepsilon[0] r
}

电势叠加原理 {
  _E_ = sum[1..n] (
    q / 4 pi varepsilon[0]
    _r_[0] r(2)
  )
}
