电场的图示法  电场线

电场线 {
  在电场中描绘一系列的曲线
  这些曲线上每一点的切线方向都与该点电场强度 _E_ 的方向一致

  #[性质] {
    它不形成闭合回路,也不中断,而是起子正电荷(或无穷远处),止于负电荷(或无穷远处)
    任何两条电场线不相交,即静电场中没一点的电场强度是唯一的
  }
}

电通量

#[定义] {
  通过电场中任意给定面的电场线数
}

微分形式 [
  _E_ c.. d _S_
] = d Psi[e]

积分形式 [
    int[S] d Psi[e]
    int[S] _E_ c.. d _S_
] = Psi[e]

S 为闭合曲面 [
  oint[S] _S_ c.. d _S_
] = Psi[e]

高斯定理

Psi[e] = {
  点电荷电场 {
    正球面 {
      oint[S] d Psi[e]
      oint[S] {q d S / 4 pi varepsilon[0] r(2)}
      q varepsilon[0]
    }

    点电荷在闭合曲面外 {
      0
    }
  }

  任意带电系统 [
    oint[S] _E_ cdot d _S_
    oint[S] (sum[1..n] _E [dot]) cdot d _S_
    sum[*] oint[S] _E_ [dot] cdot d _S_
    sum[*] q[dot] / varepsilon[0]
  ]
}

静电场的高斯定理 {
  通过真空中的静电场中任意闭合曲面的电通量 Psi[e]
  = 包围在该闭合曲面内的电荷代数和 sum[*] q 的 1 / varepsilon[0]
  而与闭合曲面外的电荷无关
}
