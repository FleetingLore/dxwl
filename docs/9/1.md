# 9-1  电场  电场强度

## 电场

### 电荷守恒定律

在一孤立系统内,无论发生怎样的物理过程,系统的电荷量保持不变

### 电荷的量子化

电荷只能取分立的、不连续的量值

### 电荷的相对论不变性

电荷的电量与运动状态无关

## 库仑定律

_F_ = k {q[1] q[2] / r(3)} _r_[0]

k = 1 / 4 pi varepsilon [0]

### 静电力的叠加原理

空间中存在几个点电荷时, 它们共同作用于某一点电荷的静电力, 等于其他各点电荷单独存在时, 作用在该点电荷的静电力, 的矢量和.

## 电场强度

## 静电场

相对于观察者的静止的带电体的周围存在的电场

### 静电场对外的表现

处于电场中的任何带电体, 受到电场所作用的力.

当带电体在电场中运动时, 电场所作用的力将对带电体做功.

### 电场强度
  _E_ = _F_ / q[0]

## 电场强度的叠加原理

_F_ = sum[1..n] _F_ [dot]
_E_ = sum[1..n] _E_ [dot]

## 电场强度的计算

试验电荷在点电荷的电场 {
  受静电力 [
    1 / {4 pi varepsilon[0]} {q[0] q} / {r(2)} _r_ [0]
  ] _E_

  电场强度 [
    _F_ / q[0]
    1 / {4 π ε[0]} q/r² _r_ [0]
  ] = _E_
}

点电荷电场的球对称性 {
  在以点电荷 q 为中心的每一个球面上 {
    各点电场强度的大小相等
    正点电荷 {
      电场强度方向垂直于球面向外
    }

    负点电荷 {
      电场强度方向垂直于球面向里
    }
  }
}

点电荷系的电场
  P 点电场强度 [
    sum[1..n] _E_ [dot]
    (
      sum[1..n]
      {1 / 4 pi varepsilon[0]}
      {q[dot] / r(2) [dot]}
      _r_ [dot 0]
    )
  ] = _E_

电荷连续分布的带电体的运动 {
  微分形式 [
      {d q / 4 pi varepsilon[0] r(2)} _r_ [0]
  ] = d _E_

  积分形式 [
      int[V] d _E_
      int[V] {1 / 4 pi varepsilon[0]} {d q / r(2)} _r_ [0]
  ] = _E_

  d q = [
    体 {
      rho d V
    }

    面 {
      sigma d S
    }

    线 {
      lambda d l
    }
  ]
}

带电体在外电场中所受的作用

点电荷在电场受力 [
  q _E_
] = _F_
