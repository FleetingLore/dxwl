位置矢量 _r_
坐标系建立在参考系上
首先确定参考系和坐标系，原点为 O

位矢既有大小又有方向
质点 P 可用 x, y, z 三个坐标确定

记位矢
overrightarrow{OP} = _r_ = x _i_ + y _j_ + z _k_

位矢的大小
mid \mathbf r mid = r = sqrt{x² + y² + z²}

位矢的方向余弦
cos alpha = x/r, cos beta = y/r, cos gamma = z/r

运动方程
x = x(t), y = y(t), z = z(t)
r = r (t)

知道了运动方程,就能确定任意时刻质点的位置,从而确定质点的运动.
力学的基本任务之一,正是根据各种问题的具体条件,求解质点的运动方程.

质点在空间的运动路径称为轨迹
质点的运动轨迹为直线时,称为直线运动
质点的运动轨迹为曲线时,称为曲线运动
从运动方程中消去 t 可得轨迹方程
轨迹方程和运动方程最明显的区别在于,轨迹方程不是时间 t 的显函数

位移 Delta _r_
t 时刻,物体的位矢为 r[1] ,在 t + Delta t 时刻,物体在 r[2]

位移
: Delta _r_ = _r_ [2] - _r_ [1]

位移的大小的变化量
: Delta r = mid r[2] mid - mid r[1] mid

在直角坐标系中,位移的表达式
: Delta _r_
  (x[2] - x[1]) _i_ + (y[2] - y[1]) _j_ + (z[2] - z[1]) _k_$
  = Delta x _i_ + Delta y _j_ + Delta z _k_

位移的大小
: mid Delta _r_ mid$
  sqrt{(x[2] - x[1])² + (y[2] - y[1])² + (z_2 - z_1)²}
  = sqrt{Delta x² + Delta y² + Delta z²}

元位移
: Delta t to 0 时,有元位移
  d _r_
  = d x _i_ + d y _j_ + d z  _k_

元位移的大小
: 等于元路程
  mid d _r_ mid
  = d s

速度 _v_
物体位移 Delta _r_ 用时 Delta t

平均速度
: overline{_v_}
  = {overrightarrow{AB}} / {Delta t}
    {Delta _r_} / {Delta t}

瞬时速度
: 考虑 Delta t \to 0
  _v_ = lim[Delta t to 0] {Delta _r_} / {Delta t} = {d _r_} / {d t}

速度等于位矢对时间的一阶导数

平均速率
: overline{v} = {Delta s} / {Delta t}

瞬时速率
: 考虑 $Delta t to 0
  v
  = lim[Delta y to 0] {Delta s} / {Delta t}
    {d s} / {d t}
    {mid d _r_ mid} / {d t}
    mid  _v_  mid

  瞬时速率等于瞬时速度的大小

在直角坐标系中表示速度
_v_
= {d _r_}{d t}
  {d x}{d t} _i_ + {d y} / {d t} _j_ + {d z} / {d t} _k_

在直角坐标系中表示速度的模
v
= |_v_|
= sqrt{v_x² + v_y² + v_z²}

加速度 _a_

考虑物体在 A 点速度为 _v_ [A]
从 A 点运动到 B 点
在 B 点速度为 _v_ [B],记 Delta t 内速度增量为

Delta _v_ = Delta _v_ [A] - Delta _v_ [B]

平均加速度
: overline{a} = {_v_ [B] - _v_ [A]} / {Delta t} = {Delta _v_} / {Delta t}

瞬时加速度 = 加速度
: _a_ = lim[Delta y to 0] {Delta _v_} / {Delta t} = {d _r_} / {d t} = {d² _r_} / {d t²}
  加速度是速度对时间的一阶导数,或位矢对时间的二阶导数

加速度的方向
: 当 Delta t to 0 时平均加速度 {Delta _v_} / {Delta t} 或速度增量的极限方向
