--- 刚体对轴的角动量

L = J omega

--- 刚体定轴转动的角动量定理

微分形式 [
  J alpha
  J {d omega / d t}
  d (J omega) / d t
  d L / d t
] = M

积分形式 [
  int[t[0]](t[1]) M d t
  int[L[0]](L[1]) M d L
  L - L[0]
] = J omega - J omega[0]
